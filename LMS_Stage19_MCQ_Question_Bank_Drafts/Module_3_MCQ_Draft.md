### Question 1 (Order: 1)
**Topic / Category:** Software Development Lifecycle (SDLC) & Agile/Scrum  
**Difficulty:** Easy  
**Source Lesson:** Submodule 1 (SDLC & Agile/Scrum Fundamentals) & File `14. How Software development lifecycle works.docx`  

**Question Statement:**  
In modern Agile/Scrum software engineering teams, what is a "Sprint"?

- **A.** A multi-year corporate restructuring roadmap.
- **B.** A fixed time-box (typically 2 to 4 weeks) during which cross-functional teams design, build, test, and deliver a working, potentially shippable increment of software.
- **C.** A daily physical fitness exercise mandated for development teams.
- **D.** The process of terminating a software engineer's employment contract.

**Correct Answer:** **B**

**Explanation:**  
- **Why B is correct:** In Scrum methodology, a Sprint is a recurring, time-boxed iteration (usually 14–30 days) where developers, testers, and product owners commit to completing a prioritized set of user stories from the sprint backlog to deliver functional software increments.
- **Why other options are incorrect:**  
  - *A is incorrect* because multi-year planning is an enterprise executive roadmap, not an agile sprint.  
  - *C is incorrect* because sprints relate to software development cycles, not physical exercises.  
  - *D is incorrect* because employment termination is an HR separation function.

### Question 2 (Order: 2)
**Topic / Category:** Technical Architecture: Frontend vs. Backend  
**Difficulty:** Medium  
**Source Lesson:** Submodule 2 (Technical Landscape: Frontend, Backend, Databases & Infrastructure) & File `15. Tech Stack - List of IT skills.docx`  

**Question Statement:**  
An IT recruiter is screening candidates for a "Senior Frontend Engineer" requisition. Which combination of programming languages, libraries, and frameworks represents genuine frontend competencies?

- **A.** React.js, TypeScript, Angular, Redux, HTML5/CSS3.
- **B.** Oracle PL/SQL, Cassandra, MongoDB, PostgreSQL.
- **C.** Linux Kernel, Ansible, Terraform, Kubernetes.
- **D.** Apache Spark, Hadoop, Kafka, PySpark.

**Correct Answer:** **A**

**Explanation:**  
- **Why A is correct:** Frontend development encompasses user interface (UI) and user experience (UX) engineering running in web browsers or client devices. React.js, Angular, Vue, TypeScript, Redux, and modern HTML5/CSS3 are core frontend technologies.
- **Why other options are incorrect:**  
  - *B is incorrect* because Oracle, PostgreSQL, Cassandra, and MongoDB are relational and NoSQL database management systems.  
  - *C is incorrect* because Linux, Ansible, Terraform, and Kubernetes represent DevOps, Cloud, and Infrastructure automation tools.  
  - *D is incorrect* because Spark, Hadoop, and Kafka represent Big Data and real-time streaming technologies.

### Question 3 (Order: 3)
**Topic / Category:** Relational vs. NoSQL Databases  
**Difficulty:** Medium  
**Source Lesson:** Submodule 2 (Technical Landscape: Databases) & File `15. Tech Stack - List of IT skills.docx`  

**Question Statement:**  
What is the fundamental architectural difference between Relational Databases (RDBMS) and NoSQL Databases that an IT recruiter should verify when analyzing technical project descriptions?

- **A.** RDBMS stores data in structured tables with predefined schemas and SQL queries (e.g., PostgreSQL, MySQL), whereas NoSQL stores unstructured/semi-structured data in flexible formats like document, key-value, or graph models (e.g., MongoDB, DynamoDB).
- **B.** RDBMS can only run on mobile phones, while NoSQL only runs on mainframe supercomputers.
- **C.** RDBMS does not require any computer programming, while NoSQL is written in pure machine binary code.
- **D.** There is no difference; RDBMS and NoSQL are interchangeable brand names for the same software.

**Correct Answer:** **A**

**Explanation:**  
- **Why A is correct:** Relational Database Management Systems (RDBMS like Oracle, MySQL, SQL Server, PostgreSQL) use structured tabular relations, rigid schemas, and ACID transactions. NoSQL systems (like MongoDB, Couchbase, Cassandra, Amazon DynamoDB) provide schema-less, highly distributed storage optimized for horizontal scalability and rapid data model evolution.
- **Why other options are incorrect:**  
  - *B is incorrect* because enterprise databases run across server clusters, private clouds, and public cloud platforms.  
  - *C is incorrect* because both systems require specialized programming, query languages, and database design skills.  
  - *D is incorrect* because they represent fundamentally distinct architectural data paradigms.

### Question 4 (Order: 4)
**Topic / Category:** Cloud & Containerization Technologies  
**Difficulty:** Medium  
**Source Lesson:** Submodule 3 (Cloud Technologies, Microservices & Containerization for Recruiters) & File `IT Technologies info.docx`  

**Question Statement:**  
A client asks for a DevOps Engineer with hands-on "Docker and Kubernetes" expertise. What core capability do Docker and Kubernetes provide in modern enterprise application deployment?

- **A.** Designing graphical banners and website marketing logos.
- **B.** Containerizing applications into portable, lightweight packages (Docker) and automating their deployment, scaling, and orchestration across distributed server clusters (Kubernetes).
- **C.** Managing monthly employee tax filing and provident fund contributions.
- **D.** Manufacturing physical microchips and motherboard processors.

**Correct Answer:** **B**

**Explanation:**  
- **Why B is correct:** Docker packages application code along with its dependencies, runtimes, and libraries into standardized, isolated containers. Kubernetes (K8s) is the leading open-source container orchestration engine that automates container scheduling, auto-scaling, load balancing, and self-healing across multi-node server clusters.
- **Why other options are incorrect:**  
  - *A is incorrect* because graphical design is handled by UI/UX designers using tools like Figma or Adobe Creative Suite.  
  - *C is incorrect* because payroll and tax filing belong to corporate finance and payroll systems.  
  - *D is incorrect* because Docker and Kubernetes are software solutions, not hardware semiconductor fabrication processes.

### Question 5 (Order: 5)
**Topic / Category:** IT Industry Domains & Regulatory Context  
**Difficulty:** Hard  
**Source Lesson:** Submodule 4 (IT Industry Domains: BFSI, Healthcare, E-Commerce, Telecom & IoT) & File `15.1. List of Domains projects in IT.docx`  

**Question Statement:**  
An IT recruiter is sourcing for a "Senior Data Engineer" for a US Healthcare client. Why is candidate domain experience with regulations like HIPAA (Health Insurance Portability and Accountability Act) considered a major competitive differentiator?

- **A.** Because HIPAA regulates the speed of internet cables in US hospitals.
- **B.** Because HIPAA mandates strict legal data privacy, security safeguards, and encryption protocols for handling sensitive Protected Health Information (PHI), where software data breaches carry severe federal penalties.
- **C.** Because candidates with HIPAA certification are exempt from paying federal income taxes.
- **D.** Because HIPAA dictates which programming language syntax must be used for writing mobile user interfaces.

**Correct Answer:** **B**

**Explanation:**  
- **Why B is correct:** In the Healthcare and Life Sciences IT domain, software developers and data engineers must comply with HIPAA regulations regarding patient electronic Protected Health Information (ePHI). Engineers with prior healthcare domain experience understand de-identification, role-based access control (RBAC), audit logging, and data encryption, reducing compliance risk for the hiring client.
- **Why other options are incorrect:**  
  - *A is incorrect* because telecommunication standards are governed by IEEE and FCC, not healthcare privacy acts.  
  - *C is incorrect* because healthcare compliance has no relation to individual employee income tax obligations.  
  - *D is incorrect* because HIPAA defines security and privacy outcomes, not programming language syntax.

### Question 6 (Order: 6)
**Topic / Category:** Practical Recruiter Scenario: Technical Skill Stack Validation  
**Difficulty:** Hard  
**Source Lesson:** Submodule 2 (Technical Landscape) & Submodule 3 (Cloud & Microservices)  

**Question Statement:**  
A recruiter is tasked with hiring a "Java Full-Stack Developer" with Microservices architecture. During a telephonic screening call, the candidate states: *"I have 5 years of Java Full-Stack experience. On the backend, I write Java Core and Spring Boot with REST APIs. On the frontend, I develop single-page applications using React.js and Redux. For data persistence, I use PostgreSQL and Hibernate, and I deploy services using Docker on AWS."* Does this candidate's profile match the core technical requirements for a modern Java Full-Stack role?

- **A.** No; the candidate only possesses database administration skills.
- **B.** No; React.js is a mobile operating system and cannot be used with Java.
- **C.** Yes; the candidate demonstrates a complete, cohesive modern full-stack profile spanning frontend (React.js/Redux), backend (Spring Boot/Java), database (PostgreSQL/Hibernate ORM), and cloud deployment (Docker/AWS).
- **D.** No; modern full-stack development prohibits using more than one technology at a time.

**Correct Answer:** **C**

**Explanation:**  
- **Why C is correct:** A complete full-stack engineer manages presentation tier (React/Redux), application logic tier (Java/Spring Boot REST microservices), data persistence tier (PostgreSQL/Hibernate), and deployment workflows (Docker/Cloud). The candidate's stated stack represents the industry benchmark for modern Java full-stack engineering.
- **Why other options are incorrect:**  
  - *A is incorrect* because the candidate clearly builds UI applications, REST APIs, and microservices, not just database administration.  
  - *B is incorrect* because React.js is the premier JavaScript frontend web library, widely paired with Spring Boot backends.  
  - *D is incorrect* because modern multi-tier web applications inherently integrate specialized technologies across each architectural layer.
