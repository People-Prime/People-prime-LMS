## 4. Assessment Architecture Compatibility

All 48 drafted questions strictly adhere to the technical structure required by `core.ModuleQuestion`:

```python
{
    "module": <module_id>,  # e.g., 2, 3, 4, 5, 6, 7, 8, or 9
    "question_text": "<Clear, professionally phrased question statement>",
    "question_type": "MULTIPLE_CHOICE",

    "is_required": True,
    "is_active": True,
    "options": [
        {"id": "opt_1", "text": "...", "is_correct": False, "explanation": "..."},
        {"id": "opt_2", "text": "...", "is_correct": True,  "explanation": "..."},
        {"id": "opt_3", "text": "...", "is_correct": False, "explanation": "..."},
        {"id": "opt_4", "text": "...", "is_correct": False, "explanation": "..."}
    ]
}
```

- **Option Count:** Exactly 4 options per question.
- **Correct Answers:** Exactly one option has `is_correct = True`; three options have `is_correct = False`.
- **Explanations:** Comprehensive explanations provided for both why the correct answer is valid and why each distractor is incorrect.
- **Anti-Cheat Readiness:** Compatible with `ModuleQuestionSerializer` sanitization (learners receive only `id` and `text`).
